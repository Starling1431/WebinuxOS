# WebinuxOS - Ubuntu Web Simulator

A web-based Ubuntu simulator that replicates the look and feel of an Ubuntu terminal and desktop in the browser. Perfect for demos, teaching, or fun!

## Features

- Interactive terminal with basic commands (`help`, `echo`, `date`, `clear`, `neofetch`).
- Custom `neofetch` command showing system info and ASCII art.
- Desktop environment with draggable icons.
- Virtual mouse cursor optimized for touch devices.
- Dark mode toggle for comfortable viewing.
- Search integration using DuckDuckGo.
- File explorer simulated with basic folder navigation.
- Notepad app with local storage save.
- Responsive design for mobile and desktop.

## Technologies Used

- HTML, CSS, JavaScript (Vanilla)
- Progressive Web App manifest config
- Service Worker for offline support
- DuckDuckGo instant answer API for search

## Installation

Simply clone or download the repo and open `index.html` in a modern web browser. No build steps or dependencies required.

git clone https://github.com/yourusername/webinuxos.git
cd webinuxos
open index.html


## Usage

- Use the terminal to type commands.
- Click desktop icons to open apps.
- Toggle dark mode in settings.
- Use the file explorer and notepad for file simulation.
